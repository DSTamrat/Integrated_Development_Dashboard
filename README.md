#  **Integrated Development Dashboard**  
### *A colorful, interactive analytics dashboard powered by synthetic data*

---

##  **Introduction**
This project is an end‑to‑end **interactive development dashboard** built with Python, Streamlit, and Plotly. It simulates a real engineering environment by generating **synthetic operational data** and visualizing it through **colorful, dynamic charts**.  

The dashboard helps teams monitor commits, test performance, CPU usage, latency, and environment health across multiple projects—all in one place.

---

##  **Problem Statement**
Engineering teams often struggle with:
- Scattered metrics across multiple tools  
- No unified view of development activity  
- Difficulty spotting performance issues early  
- Lack of real‑time visibility into system health  

This leads to slower debugging, inefficient workflows, and delayed releases.

---

##  **Objectives**
The project aims to:
- Create a **single, interactive dashboard** for engineering metrics  
- Use **synthetic data** to simulate real‑world Dev/Test/Prod environments  
- Provide **colorful, intuitive visualizations** for quick decision‑making  
- Demonstrate a complete **start‑to‑finish data engineering workflow**  
- Showcase clean, reproducible, well‑documented code  

---

##  **Methodologies Used**
- **Synthetic Data Modeling**  
  - Randomized time‑series generation for commits, tests, CPU, latency  
- **ETL‑Style Processing**  
  - Data cleaning, filtering, and transformation  
- **Interactive UI/UX Design**  
  - Streamlit widgets for filtering and exploration  
- **Visual Analytics**  
  - Plotly charts for time‑series, distributions, and KPIs  
- **Live Simulation**  
  - Real‑time metric updates to mimic system load  

---

---

##  **Key Findings**
From the synthetic dataset and dashboard interactions:
- **Dev environments** show the highest commit activity  
- **Test pass rates** fluctuate more in Test than Prod  
- **CPU usage** varies widely, highlighting potential load issues  
- **Latency spikes** can be easily spotted through violin plots  
- **Cross‑project comparisons** reveal performance differences quickly  

These insights demonstrate how a unified dashboard improves visibility and decision‑making.
